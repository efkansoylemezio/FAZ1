# Security Policy

## Güvenlik açığı bildirimi

Bir güvenlik açığı bulursanız lütfen public issue AÇMAYIN.
Bunun yerine repo sahibine özel olarak ulaşın (GitHub Security Advisories üzerinden).

## Kapsam

- Dependency güvenliği: Dependabot + npm audit ile izlenir
- Secret yönetimi: gitleaks pre-commit + GitHub secret scanning
- Branch protection: main dalı korumalı, PR review zorunlu
